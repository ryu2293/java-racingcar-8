## 기능 목록

### 1. 자동차 객체

[x] Car 객체(클래스)를 생성한다.
[x] Car는 무작위 값(4 이상)에 따라 전진(move)하는 기능을 가진다.

### 2. 사용자 입력

[ ] 경주할 자동차 이름들을 쉼표(,)로 구분하여 입력받는다.
[ ] 시도할 횟수를 입력받는다.
[ ] [예외] 자동차 이름은 5자 이하만 가능하며, 빈 값을 허용하지 않는다.
[ ] [예외] 시도할 횟수는 1 이상의 숫자만 입력 가능하다.

###  3. 경주 진행

[ ] 입력된 횟수만큼 각 자동차의 전진/멈춤 로직을 실행한다.

### 4. 실행 결과

[ ] 각 차수별 실행 결과를 형식에 맞게 출력한다. (예: pobi : --)
[ ] 최종 우승자를 선정하여 형식에 맞게 출력한다. (공동 우승자 처리 포함)
